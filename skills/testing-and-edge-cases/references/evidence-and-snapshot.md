# 证据来源与代码版本

用于旧版本是否证明当前版本、样例是否证明整体。显式保留用户报告的来源，不能把口述写成自己实测；不能因当前没有运行就说测试失败。当前问题若只是版本归属，答清后停止。

1. **明确要验证什么**：把当前目标变成可观察行为，例如返回位置不同、边界输入不越界；不以“样例都对”代替具体要求。

2. **核对已有证据**：区分测试计划、手动推演、用户报告和实际运行记录，检查运行绑定的代码版本。旧版本记录可以作历史材料，不能证明当前快照。

3. **限定结论**：通过只覆盖这些测试所检查的行为；不足时列出最相关的缺口，不穷举无关极端情况，不宣布Goal完成或把样例成功当正确性证明。
