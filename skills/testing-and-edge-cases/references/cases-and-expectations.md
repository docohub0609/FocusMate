# 合法用例与预期性质

用于选择边界或定位实际差异。按合法输入条件、暴露的风险、预期性质说明用例；多解按题目性质验证，不强求逐字等于样例。仅在用户需要测试建议且确有缺口时建议检查，不为已回答的局部问题另开测试任务。

1. **选择相关边界**：依据题目允许的范围选择最小规模、空或单元素、重复值、极值及结构退化情况；题目不允许的空输入不能当成必须通过的测试。

2. **确定预期依据**：每个建议用例说明为什么合法、检查哪个风险、预期如何由题意推出。答案不唯一时检查性质，不强求与某个示例输出逐字相同。

3. **定位差异**：已有当前运行记录时对照输入、预期和实际输出，区分异常、超时、输出错误与未执行。没有记录时可静态分析，但不编造运行结果。
