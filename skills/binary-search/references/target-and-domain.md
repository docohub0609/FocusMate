# 目标与单调范围

用于搜索目标、合法域和端点含义。区分完整合法域与实现选出的搜索段；若材料明确答案包含在域内，不重复质疑该保证。半开数组待查下标不含右端点，最终答案候选可能含该端点。

1. **明确查找目标**：要找任意匹配、首末匹配、插入位置，还是满足条件的答案边界？核对无解和末端位置的返回约定。

2. **核对单调依据**：依据题目与判定逻辑说明真假随位置如何变化；升序、降序及真假方向分别处理，不能凭“用了二分”认定单调。

3. **解释区间约定**：沿用材料明确给出的开闭约定，后续更新与返回解释保持一致；不要因熟悉另一模板，把闭区间改写成半开区间。说明端点开闭、待检查的位置和答案允许的位置。边界答案可能在半开区间的右端点，不能混成“答案必在内部”。
