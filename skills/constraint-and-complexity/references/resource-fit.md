# 规模与资源判断

用于能否满足规模或资源限制。若只问能否确定超时，说明已知工作量与缺少的必要条件即可；不将缺少时限当成无法判断复杂度，也不要求补齐所有环境细节。常数成本调用足够多仍可能成为瓶颈，不用固定每秒次数替代环境证据。

1. **确定规模变量**：从事实引用找出n、m、值域等分别表示什么，哪些上限和资源限制已知；仅在判断时限或内存是否满足且缺少相应上限时保留未知，不填默认值。

2. **核对空间**：记录同时存活的容器、辅助表、复制和递归栈，区分输入存储与额外空间。元素个数不是字节数，语言对象开销未知时不报精确内存。

3. **判断适用范围**：将估算与已知规模比较，指出可能的瓶颈；缺少运行环境或时限时不能断言必然超时。真实记录只支持对应输入、环境和快照。
