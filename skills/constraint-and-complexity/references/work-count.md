# 实际操作次数

用于循环或缓存成本估算。双指针虽有嵌套循环，每个指针若总共只前进 n 次，总次数仍可能线性；需另外核对单次成本。缓存递归按不同状态数与每状态转移数估算。精确次数应标明计数对象，如 check 调用次数，不等于全部机器操作。具体代入沿用精确计数式；上界和渐近量级分别标明，不能将省略低阶项的估算改称精确次数。

1. **数实际工作量**：沿当前代码统计循环次数、每轮操作成本、递归分支与深度。顺序段通常相加，嵌套段要检查内层次数是否依赖外层；不能见两层循环就一律判平方。

2. **检查隐含成本**：考虑实际使用的排序、切片、拷贝、容器操作和缓存。区分最坏、平均或摊还成本，不能不说明前提就互换。
