# 覆盖与终止

依据当前目标检查循环或递归如何推进与终止、是否重复加入同一状态、提前退出会漏掉什么。先核对邻接关系是否符合有向性，孤立点是否被表示；树的根与节点编号缺失且影响当前判断时才保留未知。

父节点过滤解决一次树遍历中是否沿原边退回；覆盖全图则取决于是否启动了必要的分量起点。这是两个判断：森林中的每棵树仍可用父节点过滤，不因存在多个分量就断言必须换成 visited。

若用户求全图连通分量，追踪一个包含孤立点或两个分量的允许输入，检查是否启动必要的其他起点；若只问两点连通，不因没有遍历所有分量而判错。只依据已有代码判断局部行为，不能凭片段断言完整程序错误。
