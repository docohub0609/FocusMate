# 访问控制

检查当前代码如何区分未访问、已发现、已处理、递归路径中的节点，核对标记与入队或递归的先后关系。没有 visited 数组也可能有其他正确控制机制，不能据此直接判错。

从题目允许的最小边结构静态追踪一次：无向边 u 到 v 后，是否会再回到 u；当前机制是否阻止重复扩展。跳过父节点可适用于有保证的树，但不能自动推广到一般有环图。区分允许有环与这次输入确实有环。

只说明当前局部风险成立的条件；不返回完整遍历代码。引用请求、事实或代码 ref，运行记录仅证明其绑定快照，未执行不得声称死循环已实测。

题目已保证为树且用户只问跳父节点时，按这个保证检查即可；根 parent 是否避开所有编号不是普遍必要条件，应检查是否实际误过滤邻居。单线程相邻入队与标记之间没有另一个节点自动插入执行的机会；允许重复加入与是否重复扩展也需分开。
