# 路径与代价

先确认用户求连通、路径、边数还是权重和，再核对有向性、边权条件与距离更新依据；这些目标不能混用一种结果含义。费用判断需要边权而材料缺失时保留未知，不默认一般最短路适用条件。

若当前请求讨论最短路，检查按层遍历得到的边数能否代表题目代价。用题目允许的少量边比较局部路径代价，说明权重条件为何影响判断；不能把 BFS 的边数默认当成一般带权最短距离。连通性可以用不同遍历，不强迫替换用户合理方法。

发现必须引用传入 ref，运行证据只证明绑定快照；未提供完整实现时仅评价已有部分。不输出完整最短路算法、完整解答或完整推导。

按给定路线累计权重，逐项核对加法；所有边权为 1 是边数普遍代表费用的充分条件，不能当作某条路线两者相等的必要条件。
